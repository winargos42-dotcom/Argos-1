Архитектура: существующий FastAPI, SQLite и последовательная очередь для общего ядра. Панель получает SSE через авторизованный fetch. Bearer token хранится только в оперативной памяти вкладки. Отмена генерации закрывает HTTP-поток; это не гарантия мгновенного освобождения вычислителя Ollama. После запроса отмены уже завершённая операция сохраняет фактический результат.
